# Anki Flashcard Studio

An intelligent multi-course flashcard generator and sync studio for Anki and Google Drive, powered by Gemini 3.8 Flash and Streamlit.

## Features
- **3-Cloze Biochemical Equation Standard:** Formats pathway reactions as intuitive, atomic equations (`Substrate ——[Enzyme]——> Product`).
- **Deep Mechanistic & Thermodynamic Coverage:** Covers $\Delta G'^\circ$ vs. $\Delta G'$, active-site residues, metal ion coordination, and metabolic regulation.
- **Direct Google Drive Integration:** Automatically inspects lecture slides and updates course `.apkg` packages in place.
- **One-Click Deploy:** Hosted on Google Cloud Run with automated CI/CD via GitHub Actions.
